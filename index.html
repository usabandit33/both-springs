One garage door spring broke. Ask if both get replaced.

When a torsion spring snaps in Chicago, the matching spring has usually lived the same number of opens and closes. Homeowners who change only the broken one often pay for a second trip soon after. Use this checklist before you book.

  • Confirm it is a torsion pair on the shaft above the door — not a single spring or extension springs along the tracks.
  • Ask whether both springs are replaced on this visit.
  • Ask whether the trip or service-call fee credits if you approve the job the same day.
  • Ask for the cycle rating they will install and whether both sides match.
  • Ask where the truck is based tonight and whose name will be on the invoice.
  • Get the arrival window and any after-hours rate in writing before work starts.
